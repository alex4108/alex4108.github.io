Migrating 4,600 SQL Server databases

Legacy binaries, SQL Server Standard licensing, separate domains, limited network capacity, and a strict maintenance window ruled out the cleanest textbook paths. The migration used queue-driven log shipping to move most data ahead of cutover and promote databases in a controlled final window.

Designing public connectivity for an Azure SQL FCI

A series of tested designs compared Azure load-balancing, firewall DNAT, and HAProxy paths for connecting to a SQL Server Failover Cluster Instance. The work kept connectivity, high availability, and operating cost in the same architectural decision.

KBeacon Ring for Home Assistant

This local-push integration connects to KBeacon and Blue Charm BLE tags through Home Assistant Bluetooth proxies. It handles challenge-response authentication, drives audible or visual ring commands, and turns physical tag gestures into automation events without a cloud service.

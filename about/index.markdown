I’m Alex. I work where infrastructure, software, and operations meet: modernizing legacy systems, reducing repetitive work, and making production changes easier to reason about.

I’m drawn to systems whose constraints matter. That can mean moving a large database estate without a clean re-platforming path, testing lower-cost connectivity designs instead of accepting the default service, or turning a manual device workflow into a declarative tool with dry runs and read-back verification.

The thread through the work is simple: understand the current state, make the smallest useful change, verify the result, and leave the next operator a safer system.

This site collects a focused set of [case studies and projects](/work/), along with the original [writing archive](/archives/).
